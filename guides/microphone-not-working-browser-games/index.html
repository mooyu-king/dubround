Microphone not working in browser games

Fix browser permission, system privacy, input selection and competing audio apps.

Your quick-start path

Illustrated workflow, not a browser screenshot. Follow the detailed instructions below for exceptions.

  1. Site permission

    Allow this site's microphone request; check the address before approving.

  2. System input

    Allow your browser to use the microphone and choose the connected input.

  3. Test the signal

    Speak normally in Mic Test. A moving meter means audio is reaching the page.

What is stopping you?

Open this site's microphone permission beside the address bar. Change Block to Ask or Allow, then reload. If access stays blocked, check system privacy settings for the browser.

01

First, isolate the problem

Open Mic Test in a normal browser tab. Start the test, allow access and speak at a comfortable volume. A moving meter means the browser receives audio; it does not prove a particular game has selected the same input. Stop the test before returning to the game. If the meter stays still, work through permission, system input and hardware below in that order.

02

Chrome and Edge: check this site's permission

Open the site controls beside the address bar and inspect Microphone permission for the current origin. Change a blocked decision to Allow or Ask, then reload and press the microphone button again. Check the selected input in browser microphone settings if several devices are connected. A managed school or work browser may prevent changes; contact its administrator instead of repeatedly approving prompts.

03

Windows: allow the browser and check the input

In Windows Settings, open Privacy & security → Microphone. Enable microphone access and the relevant app or desktop-app permission. Next open System → Sound → Input, select the microphone you actually use and test its level. A webcam mic, USB headset and Bluetooth headset are separate inputs. If Windows receives no sound, check the headset mute switch and cable before changing the game.

04

Safari and macOS

On Mac, check Safari → Settings → Websites → Microphone for this site. Also inspect System Settings → Privacy & Security → Microphone for browser access. In Sound settings, select the intended input and check its level. If you change a system permission, reopen the browser if requested. Allowing a website and allowing an application are separate decisions.

05

Phones and embedded browsers

Open the page directly in Safari or Chrome rather than an in-app preview. Review both the browser app's microphone permission and the site's permission. Keep the page visible during recording, end any phone call and disconnect a Bluetooth headset temporarily to isolate routing problems. Permission controls differ by OS version: use your device's settings search for Microphone if the label has moved.

06

Permission works, but the take is silent or distorted

Close other recording or meeting applications, choose the input again and make a short test. Use headphones so reference playback is not recorded as your voice. If the sound crackles, move away from the mic or reduce input gain; shouting is not a fix. If the browser reports the device is busy, stop other audio sessions and retry. Save any work before restarting the browser.

07

Check the frame and report a reproducible failure

If Mic Test works but the embedded stage does not, open the full-page game and repeat one short take. Note the browser and OS version, whether the meter moved, and the exact error. Do not send your private recording or room credential. A browser permission prompt cannot repair an unsupported codec or an unavailable Pack: those are separate loading problems.
